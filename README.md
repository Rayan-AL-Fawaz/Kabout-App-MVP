# Kabout App - Minimal Viable Product (MVP)

## Project Overview
This is the Minimal Viable Product (MVP) for **Kabout**, an automotive service application designed to connect car owners with workshops. It demonstrates the core logic and user interface flow of the system.

## Key Features Implemented
1. **User Authentication (Simulation):** Basic login interface for users.
2. **Request Customized Quote:** Allows users to submit vehicle details, describe issues, and request quotes from workshops.
3. **Book Service Appointment:** Enables users to select a workshop, choose a date and time, and confirm their booking.

## Setup & Execution Steps
This MVP is built using standard web technologies (HTML/CSS/JS) to ensure cross-platform compatibility without complex server setups.

**To run the application:**
1. Download the `index.html` file from this repository.
2. Double-click the file, or right-click and select "Open with" -> Google Chrome (or any preferred web browser).
3. The application will launch instantly in the browser. You can navigate through the screens to test the use cases.
